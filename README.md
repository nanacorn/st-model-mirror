# Model Mirror (Vertex → AI Studio)

SillyTavern 확장. **Google Vertex AI** 모델 목록에 있는 모델을 **Google AI Studio** 모델 목록에도 똑같이 넣어 준다.

- 모델 추가 확장(어떤 이름이든)으로 Vertex 목록에 넣은 모델도 그대로 따라온다. 나중에 추가한 모델도 바로 반영된다.
- AI Studio 목록 맨 위에 "Vertex 목록에서 가져온 모델" 묶음으로 보인다.
- 고른 모델은 새로고침해도 유지된다.

쓰는 곳: Vertex 모델을 AI Studio 형식의 리버스 프록시(미국 중계)로 쓸 때.
